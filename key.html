DeepSeek Harness · 桌面版

欢迎使用 · 首次使用需要配置 API Key

DeepSeek Harness 通过你的 API Key 在本地调用 DeepSeek 模型。下面教你 30 秒拿到并填好它。

如何获取 API Key（三步）

  1. 1
    打开 DeepSeek 开放平台（需登录你的 DeepSeek 账号）。
  2. 2
    进入 「API Keys」 页面，点击 「创建 API Key」，给密钥起个名字后生成。
  3. 3
    点击 复制，把以 sk- 开头的密钥粘贴到下面的输入框，然后保存即可。
🔒 Key 仅保存在本机用户目录（AppData），不会随安装包分发，也不会上传到任何服务器。
